## 3. 跨模块 sequencing rationale

UE 依赖图：`Core → CoreUObject → AssetRegistry/Streaming → RHI → RenderCore/RDG → Renderer`（Slate 正交）。

- A 先行：任何题跑起来前必须先走通"C++ 代码如何变成可被 UE 加载的 Module"。UHT/UBT/`.Build.cs` 是 UE 打破"纯 C++ 模板剥皮"直觉的第一处。
- B 在 C/D 前：容器/字符串的 UE 特有语义（`FString` ≠ `std::string`，`FName` 池化 ID，`FText` 本地化懒求值）是后续模块的底层词汇。
- C 在 D 前：`TSharedPtr/TWeakPtr/TUniquePtr` 是"非 UObject 的生命周期管理"，与 UObject GC 并存。先钉 C++ 所有权，D 里才分得清两套体系。
- D 是枢纽：UObject/反射/GC 决定 UE 世界一切（资产、网络、蓝图、序列化、编辑器都建在此层）。
- E 在 D 后：资产系统建立于 UObject + UPackage + 序列化。
- F 在 C/D 后、G 前：并发跨多线程，"哪些对象不能跨 GC 裸指针持有"需 D 前置。F 末题（ENQUEUE_RENDER_COMMAND）是通往 G 的钥匙。
- G 在 H 前：RHI 是 RDG 的底层原语。G 教"能读懂一次最小 PSO+Draw 的传统路径"，H 立即切 RDG。
- H 压轴：RDG 与 stdexec **结构同构最强**（lazy graph + pass 描述 + builder 管生命周期 + Execute 时才 compile），作收束点让学员秒懂"这就是 sender graph"。
- I 正交，放尾可选。
- J 放 Cap1 前：网络依赖 D（UObject/反射驱动 replication）与 F（网络任务在 TaskGraph/专用线程），但不依赖 G/H。放 I 后、Cap1 前，让 Cap1 可选择性纳入网络维度。
- Cap1 先：把 A-H 能力串成可运行系统；Cap2 后：带心智模型去读源码，避免无框架地被淹没。

## 4. 模块 01：心智模型（概览）

**定位**：纯读文件，无代码。针对 stdexec/纯 C++ 专家最易撞墙处预先拆雷。

**必讲 5 个 mindset shift**：
1. Module-first, not file-first（代码归属 Module + LoadingPhase）
2. Reflection before types（UHT 在编译器之前跑，代码生成产生 `.generated.h`）
3. Game/Render/RHI thread 分线一等公民（跨线程值捕获 + 延迟执行）
4. GC ownership vs C++ ownership 两套并存（UObject 由 GC 管，非 UPROPERTY 裸指针 GC 不可见）
5. RDG = lazy graph（与 sender graph 的类比表——**本课程核心教学杠杆**）

**每题必答四固定问题**：执行真正开始时刻？生命周期拥有者？涉及哪些 Named Thread？涉及 UObject 时怎么对 GC 可见？

**必画五张图（随模块触发）**：模块依赖图 / 线程时序图 / 对象生命周期图 / 反射可见性图 / RDG pass 图。

### 模块 A — 构建系统与模块生命周期
- 关键字：`IModuleInterface`, `IMPLEMENT_MODULE`, `FModuleManager`, `.Build.cs`, `Public/PrivateDependencyModuleNames`, `ELoadingPhase`, `UBT`, `UHT`

### 模块 B — 核心容器与字符串
- 关键字：`TArray`, `TMap`, `TSet`, `TInlineAllocator`, `FString`, `FName`, `FNamePool`, `FText`, 迭代器失效
- 范围：容器语义差异 / 字符串三件套 / 引用稳定性
- 3 练习；阶梯：use + inspect

### 模块 C — 内存、智能指针、委托
- 关键字：`TSharedPtr<T, ESPMode>`, `TWeakPtr`, `TUniquePtr`, `MakeShared/MakeShareable`, `FMemory`, `MallocBinned`, `DECLARE_*_DELEGATE_*`, multicast/dynamic delegate
- 范围：智能指针语义 / 分配器/LLM / **手写最小 multicast delegate（首处 implement-own）**
- 3 练习；阶梯：use → implement-own

### 模块 D — UObject / 反射 / GC（枢纽）
- 关键字：`UCLASS`, `UPROPERTY`, `UFUNCTION`, `GENERATED_BODY`, `.generated.h`, `NewObject`, `CreateDefaultSubobject`, `FObjectInitializer`, CDO, `FProperty` 族, `UClass::PropertyLink`, `TObjectPtr`, `TWeakObjectPtr`, `GUObjectArray`, `RF_RootSet`, `AddToRoot`
- 范围：Hello UObject + 读 `.generated.h` / CreateDefaultSubobject 与构造阶段 / 反射遍历（inspect） / **手写 mini mark-sweep GC（implement-own）**
- 4 练习；阶梯：use → inspect → implement-own
- 教学重点：强制首次直面代码生成；区分 UObject/C++ 两套所有权

### 模块 E — 资产与加载
- 关键字：`UPackage`, `FArchive`, `FLinkerLoad/Save`, `FPackageFileSummary`, `IAssetRegistry`, `FAssetData`, `FSoftObjectPath`, `TSoftObjectPtr`, `FStreamableManager`, `FStreamableHandle`, `UAssetManager`, `PrimaryAssetType`, 硬/软引用
- 范围：UPackage + FArchive 双向序列化 / AssetRegistry 依赖查询 / StreamableManager 异步加载（与 sender 惰性类比）
- 3 练习；阶梯：use + inspect（流水线过大，不 implement-own）

### 模块 F — 并发与任务图
- 关键字：Named Threads, `FRunnable`, `FRunnableThread`, `FEvent`, `FGraphEventRef`, `FTaskGraphInterface`, `ENamedThreads`, `UE::Tasks::TTask`, `UE::Tasks::Launch/Then`, `FPipe`, `ParallelFor`, `ENQUEUE_RENDER_COMMAND`, `FlushRenderingCommands`
- 范围：FRunnable 手动线程 / TaskGraph 图 / UE::Tasks 现代 API / **ENQUEUE_RENDER_COMMAND（通往 G 的钥匙）**
- 4 练习；阶梯：use → implement-own
- 教学重点：render command 的值捕获 + 延迟执行 vs lambda 直觉

### 模块 G — RHI 与着色器
- 关键字：`FRHICommandList`, `FRHIBuffer`, `FRHITexture`, `FBufferRHIRef`, `DynamicRHI`, `FGlobalShader`, `IMPLEMENT_GLOBAL_SHADER`, `SHADER_PARAMETER`, `BEGIN_SHADER_PARAMETER_STRUCT`, `PipelineStateCache`, PSO
- 范围：RHI 资源 + CommandList 基础 / FGlobalShader compute 走一遍 / 传统 RHI draw pass（**引出 RDG 动机**）
- 3 练习；阶梯：use + inspect
- 教学重点：shader 参数是 UE 第二处代码生成

### 模块 H — RenderGraph 与场景渲染（压轴）
- 关键字：`FRDGBuilder`, `FRDGTextureRef`, `FRDGBufferRef`, `AddPass`, `SHADER_PARAMETER_RDG_*`, transient pool, auto-barrier, `FScene`, `FPrimitiveSceneInfo`, `FPrimitiveSceneProxy`, `SceneViewExtension`
- 范围：RDG 惰性图（**stdexec ↔ RDG 对应表**） / FScene 双对象镜像 / 手写 RDG Pass（implement-own）
- 3 练习；阶梯：inspect → implement-own
- 教学重点：课程核心收束——RDG 描述期 vs 执行期 = sender 惰性 vs start

### 模块 I — Slate / UMG（可选）
- 关键字：`SCompoundWidget`, `SLATE_BEGIN_ARGS`, `SNew/SAssignNew`, `UUserWidget`, `NativeConstruct`
- 范围：最小 Slate widget / UMG 绑 BP
- 2 练习；阶梯：use + inspect

### 模块 J — 网络与 Replication
- 关键字：`UNetDriver`, `UNetConnection`, `UChannel`, `FNetworkGUID`, `AActor::SetReplicates`, `DOREPLIFETIME`, `Replicated/ReplicatedUsing`, `UFUNCTION(Server/Client/NetMulticast, Reliable)`, `FRepMovement`, `NetSerialize`, `FArchive::IsSaving/IsLoading` 于网络路径, `Dormancy`, `RelevancyCulling`, `Net prediction` / `ClientCorrection`
- 范围：
  1. Dedicated server + client 最小可联机工程 + Actor replication（use）
  2. Replicated UPROPERTY / RepNotify / RPC 三向（Server/Client/Multicast）（use + inspect）
  3. 自定义 `FFastArraySerializer` 或 `NetSerialize` 特化（inspect → implement-own）
  4. 网络预测与回滚最小示例（client prediction, server reconciliation）（inspect）
- 4 练习；阶梯：use → inspect → implement-own
- 教学重点：
  - replication 完全建于 D（反射元数据驱动）+ E（序列化 FArchive）+ F（网络任务线程），是 D/E/F 能力的网络维度投射
  - 与 C++ 标准无直接对应，需补 UE 网络世界观：authority / ownership / role（ROLE_Authority vs ROLE_AutonomousProxy vs ROLE_SimulatedProxy）
  - **练习统一以 PIE (Play In Editor) + "Number of Players ≥ 2" 为运行形态**，避免独立打包/部署复杂度
- 常见坑：误把 ClientRPC 当 broadcast；忘 `DOREPLIFETIME`；Replicated struct 内部含非 replicate 字段

## 6. 结课项目 1 — 集成项目（骨架）

**题目**：自定义 Asset `UHeightField` 的"运行时生成 + 异步流入 + GPU 后处理显示"。

**贯穿覆盖**：
- A：模块组织 + `.Build.cs`
- D：UHeightField 作 UObject，UPROPERTY 字段
- E：注册 PrimaryAssetType，FStreamableManager 异步加载
- F：`UE::Tasks` 预处理 + `ENQUEUE_RENDER_COMMAND` 跨线程
- G：RHI 上传 float 到 FRHITexture
- H：FRDGBuilder 三 pass 流水线（heightfield→normal→gamma→屏幕显示）

**固定约束**：≥3 次线程跨越显式标注；≥1 UPROPERTY 包装 UObject；≥1 TSharedPtr 非 UObject；禁 `FlushRenderingCommands`；禁裸 `new UObject`；禁裸 `UObject*` 成员。

**运行形态**：Editor 内可触发的 console 命令 `UELearn.Cap1.Run`；日志按阶段打印时序；每 pass 后 dump RT 为 PNG 截图。**不要求可玩 demo map**。

**可选网络扩展**：追加 console 命令在 dedicated server/client 两端触发，`UHeightField` 作 replicated property 流入客户端（串 J 模块）。此扩展 optional，不纳入必做约束。

**交付物**：三线程并行时序图 / RDG pass 依赖图 / 对象生命周期图 / 模块依赖图 / 四固定问题书面回答 / 各 pass RT 截图。
