# C09 完整审计与增量补全规格

获准日期：2026-09-11。依据根目录的全局计划、内容重构指南及本次获准方案。

## 目标与边界

面向已有现代 C++ 基础、尚未熟悉协程的工程师。37 个现有单元全部审计，按实际缺口增量修改；已有知识、题号、学生作业和历史证据保留。C09 主讲语言协议、控制流和生命周期，爬虫、RPC、mini 库分别承担使用、应用和实现练习。

写入范围为本课程，根 README 与全局计划仅更新 C09 导航和状态。复用 Windows 和已有 LearnCPP-C08-Ubuntu-24.04 WSL；不安装系统组件、不升级依赖、不增加 CI，不涉及凭据、生产、提交或推送。

## 教学与验收契约

- 覆盖链：下游任务 → 硬先修 → 核心问题与契约 → 连续推导和演进 → 正文/解析 → Student/Reference/checker → 证据 → 独立审查。每单元登记无需改、正文补强、实现/检查补强、证据补强中的适用项。
- 先修按能力引用 C02/C03/C04/C07/C08；H 只在必要的 C10 sender 基础后进入。I/O/RPC 不取代 C11 网络主课。
- Student 是可完成的 TODO 起点，不要求自动填完任何学生作业。实现型未完成必须安全、有限、明确非零失败；观察型通过只证明观察程序实际检查的行为。每个必做 Part 提供独立编辑位置、检查和完整解析。
- Reference 与学生修改隔离；独立 good 证明题目可做，代表性 bad 证明检查器会拒绝错误。禁止用输出常量、完成标记、绕过学生操作或直接调用 Reference 冒充通过。
- 每条问题或优化先有原始失败/定位，再改进和复验。没有归因证据就记录未验证，不能进入依赖该结论的演进。

## 固定实施决定

1. 以 G3 与共享 lazy_task 为样章。先完成规格审查、移动结果异常的帧泄漏复现、所有权修复、原复现复跑及非作者教学/技术审查；通过后才批量深化其余主题。
2. lazy_task 的结果提取在 RAII owner 存活期间完成；保留单次消费。mini_ref scope 在启动前计数，启动失败时加锁回滚并通知，不能把递增挪到线程启动之后。爬虫保留移动前的错误 URL。
3. H3 检查学生 my_task 的 sender、嵌套 await、sender-to-await 三条链。RPC 对齐现有 Reference：8 字节十进制长度头，body 上限 4096，Q/C/R 消息；Request 增加默认 false 的 idempotent，call 增加默认 0 的 retries，保留现有调用和类型名称。SerializationError 对应协议错误。公开 client/server 声明供检查器链接学生 src。
4. RPC 按分帧/单请求、pending 并发、超时取消、幂等重试、关闭排空组织。示例与测试仅使用回环和临时端口，不依赖外部服务。
5. F3 同契约正确性与性能驱动共用实现；取消预设倍率。steady_clock，1 次预热和 5 次独立进程采样，固定种子安排版本顺序，保留所有样本/范围/中位数。插桩计数与无插桩 IR、反汇编或 remark 分别解释；E3/F2/D3 的优化声明同样接受审计。
6. 固定规范 C++20/23、N5050/N5054，DR 与实验实现单列；exec/stdexec 不冒充 std。保留缓存 stdexec nvhpc-26.05、Asio asio-1-38-2、cppcoro 8642e98596a92be30a2b061d3ed306d959d3214e。
7. 新增局部 COROUTINE_STUDY_LIBURING_ROOT，通过 CMake 查找现有头/库，保留 pkg-config 入口。能力探针与主体检查分离；DISABLED、SKIP/未验证和 FAIL 分开。

## 验证矩阵

| 路线 | 要求 |
|---|---|
| Windows Debug/Release | 核心与受影响消费者全部构建/运行；新鲜目录，不复用迁移前缓存 |
| Windows light | 固定缓存 stdexec/Asio/cppcoro、IOCP、H3、RPC、mini 桥接 |
| WSL | C++20 runtime 与其余支持目标；liburing 2.15 queue_init 已实测成功，I2 必测 |
| Student | Reference=OFF 隔离；实现型起点预期拒绝；独立 good 和行为型 bad |
| 生命周期 | 同步/跨线程/await_suspend 返回前完成、early destruction、失败收束、一次性恢复；latch/barrier 控制，ASan/LSan 适用检查；TSan 先工具探针 |
| RPC | 正常/错误/超时/取消/断连/重试/关闭，pending 与 in_flight 最终归零 |
| 文档/实验 | 全部 Part 解析、先修反查、链接、上游入口、原样本和独立审查 |

普通测试进程外超时 30 秒，RPC 60 秒，包含退出与清理。故障注入隔离，不真实耗尽机器资源。GCC 13 缺 generator/print 仅影响对应单元；缺 Folly/Cobalt 等保留完整正文、代码、步骤并记录未验证。探针成功后主体失败必须 FAIL。
